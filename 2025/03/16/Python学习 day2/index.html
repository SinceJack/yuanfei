    1.1 条件语句（if-else）（20 分钟）

    知识点：

    • 条件语句用于根据条件执行不同代码块。
    • 基本结构：
      • if 语句：如果条件为真，执行代码块。
      • elif 语句：如果前面的 if 条件不满足，检查下一个条件。
      • else 语句：如果所有条件都不满足，执行默认代码块。
    • 语法规则：
      • 使用冒号 : 结束条件行。
      • 代码块使用缩进（通常 4 个空格或 1 个 Tab）。
      • 条件表达式使用比较运算符（==、!=、<、>、<=、>=）和逻辑运算符（and、or、not）。
    • 常见应用：判断、选择性执行。
