    2025 学习计划

    学习 > 计划 学习
    发布时间 : 2024-09-23 14:41

  • 总结

    • 一、目标与时间分配

    • 总专注时间：每天8小时（法考2小时 + 英语四级1小时 + 抖音研究与拍摄3小时 + 缓冲2小时）。
    • 缓冲时间：考虑到你目前的自制力状态，我预留了2小时作为灵活调整或额外学习/休息时间，避免计划过于紧绷。
    • 现实性：从零基础到每天8小时专注需要过渡，我们会从较短时间开始，逐步增加。

    二、新增目标分解：研究抖音并拍摄视频

    • 研究抖音（1.5小时）：
      • 分析热门视频：看5-10个视频，记录内容结构、时长、剪辑手法、标题特点。
      • 学习技巧：用B站/YouTube找抖音拍摄教程（如“5分钟教你拍爆款短视频”）。
    • 拍摄视频（1.5小时）：
      • 脚本准备：写简单脚本（主题、台词、镜头）。
      • 拍摄与剪辑：用手机拍摄（可用抖音自带工具或CapCut剪辑），目标是每天产出1个短视频，哪怕只有15秒。
    • 初期目标：第一周每天完成1个简单视频，熟悉流程后提高质量。

    三、调整后的行动计划

    第一周：起步阶段（每天5小时专注，逐步适应）

    • 目标：法考2小时 + 英语四级1小时 + 抖音研究与拍摄2小时（缩短1小时，降低难度）。
    • 日程：
      • 8:30-9:00：起床，吃早餐，调整状态。
      • 9:00-11:00：法考（2小时，用Forest锁手机，Freedom锁娱乐网站）。
        • 任务：背20个法条或做10道选择题。
      • 11:00-12:00：休息，吃饭。
      • 12:00-1:00：英语四级（1小时）。
        • 任务：背50个单词或做1篇阅读。
      • 3:00-5:00：抖音研究与拍摄（2小时）。
        • 1小时研究：看5个热门视频，记笔记。
        • 1小时拍摄：写脚本+拍一个15秒视频。
      • 5:00-5:30：奖励时间（看30分钟B站或抖音，用计时器控制）。
      • 晚上7:00-7:30：复盘（写3句心得，如“今天拍了个搞笑视频，剪辑还需改进”）。
    • 工具：
      • Forest：锁手机专注。
      • Freedom：屏蔽无关应用（除抖音研究时段外）。
      • CapCut：剪辑视频。
    • 打卡：加入法考群和抖音创作者群，每天报告进度（如“今天学了民法+拍了个视频”）。

    第二周：过渡阶段（每天6-7小时专注）

    • 目标：法考2小时 + 英语四级1小时 + 抖音研究与拍摄2.5-3小时。
    • 调整：抖音时间增至2.5小时（研究1小时+拍摄1.5小时），若适应良好可到3小时。
    • 日程变化：
      • 3:00-5:30：抖音研究与拍摄（2.5小时），任务升级为拍30秒视频。
      • 若状态好，延长至6:00（3小时）。

    第三周及以后：稳定阶段（每天8小时专注）

    • 目标：法考2小时 + 英语四级1小时 + 抖音研究与拍摄3小时 + 缓冲2小时。
    • 日程：
      • 8:30-9:00：起床，吃早餐。
      • 9:00-11:00：法考（2小时）。
      • 11:00-12:00：休息，吃饭。
      • 12:00-1:00：英语四级（1小时）。
      • 2:00-5:00：抖音研究与拍摄（3小时）。
        • 研究1.5小时：分析10个视频+学习1个新技巧。
        • 拍摄1.5小时：拍1个30-60秒视频。
      • 5:00-5:30：奖励时间（30分钟娱乐）。
      • 6:00-8:00：缓冲时间（可补学、复盘或休息）。
      • 晚上8:00-8:30：复盘。
    • 检查点：每周评估专注时长和成果（如拍了几个视频、背了多少法条），调整节奏。

    四、鞭策机制（针对新计划）

    1. 工具支持：
      • Forest：每个时段设定专注时长（如2小时法考、3小时抖音），不完成树枯萎。
      • Freedom：每天9:00-5:00屏蔽无关娱乐应用（抖音研究时段例外，但严格计时）。
      • Habitica：把“拍视频”“背单词”设为任务，不完成掉血。
    2. 社交鞭策：
      • 加入抖音创作者群，每天发视频链接请教意见。
      • 法考和英语群继续打卡，增加“抖音进度”报告。
    3. 惩罚与奖励：
      • 惩罚：未完成8小时专注，禁止夜宵或捐10元。
      • 奖励：完成任务后，看1小时抖音/B站（用计时器）。
    4. 环境：
      • 抖音拍摄需要空间，整理房间一角作为“拍摄区”，学习时离开此区域，避免分心。

    五、应对分心与头疼眼干

    • 分心：抖音研究时段严格计时（1.5小时），超出后用Freedom锁住。其他时间段完全屏蔽。
    • 头疼眼干：
      • 每专注50分钟休息10分钟（50-10法则），看看窗外放松眼睛。
      • 用护眼模式（MacOS/iOS有“夜间模式”），滴眼药水缓解干涩。
      • 避免熬夜，晚上10:30前上床，保持精力。

    六、长期动力

    • 法考：成为律师，帮助他人，改变生活。
    • 英语四级：拿到学位，提升自信。
    • 抖音：拍出爆款视频，获得关注甚至收入。
    • 每日提醒：在桌面贴纸条“每专注1小时，我离目标近一步”。

    七、起步行动（今天）

    1. 下载Forest和Freedom，设定9:00-11:00为法考时间，锁住娱乐。
    2. 开始研究抖音：挑5个视频，记笔记（1小时）。
    3. 拍第一个15秒视频：用手机随便录一句“今天开始改变！”（1小时）。
    4. 晚上复盘：写下感受。

    总结

    新计划每天8小时专注（法考2小时 + 英语1小时 + 抖音3小时 + 缓冲2小时），从第一周5小时起步，逐步适应。工具（Forest/Freedom）和社交（学习群）提供鞭策，惩罚与奖励增加动力。关键是从小步开始，今天就行动起来！
